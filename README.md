# Merry Christmas · 冬日记忆

本地互动网页，默认加载提供的 8 张照片。背景音乐从提供的 MP4 音轨播放，视频画面不会显示。

## 本地预览

在项目目录运行：

```powershell
node server.js
```

然后打开 <http://localhost:4173>。

## 互动方式

- 粒子组成金色圣诞树；鼠标拖动空白处可旋转树。
- 张开手掌让粒子和照片散开，握拳让它们归树；捏合可拖动照片。
- 点击照片可放大查看；照片不带备注。
- 点右上角音乐按钮播放或暂停 MP4 音轨。
- 摄像头手势需要通过 localhost 或 HTTPS 打开，并允许浏览器访问摄像头。首次启用会从 CDN 下载 MediaPipe 手势识别组件和模型。
- 摄像头画面仅在浏览器本地用于手势识别，不会上传到服务器。
