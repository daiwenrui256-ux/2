# Merry Christmas · 冬日记忆

本地静态互动网页，默认加载你提供的 8 张照片。背景音乐通过页面里的播放按钮从你提供的 MP4 音轨播放，视频画面不会显示。

## 本地预览

在项目目录运行：

\`\`\`powershell
node server.js
\`\`\`

然后打开 <http://localhost:4173>。

## 互动方式

- 粒子组成金色圣诞树；鼠标拖动空白处可旋转树。
- 张开手掌让粒子和照片散开，握拳让它们归树；捏合可拖动照片。
- 点击任一照片可放大查看；照片不带备注。
- 点右上角音乐按钮播放或暂停视频里的音轨。浏览器要求先点击按钮后才允许播放；音乐源 MP4 保存在 `assets/music-source.mp4`。
- 摄像头手势需要通过 localhost 或 HTTPS 打开，并允许浏览器访问摄像头。首次启用会从 CDN 下载 MediaPipe 手势识别组件和模型。
- 照片和 MP4 保存在项目的 assets 目录中；当前页面不会把摄像头画面上传到服务器。
